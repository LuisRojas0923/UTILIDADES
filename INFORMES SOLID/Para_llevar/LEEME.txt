INFORMES SOLID - Contenido para llevar a otra ubicación
========================================================

Esta carpeta debe contener todo lo importante del proyecto.

YA INCLUIDO AQUÍ:
  • .classpath, .project   → Configuración del proyecto Java
  • LEEME.txt, copiar_contenido.ps1

PARA COMPLETAR LA COPIA (elegir una opción):

  1) Ejecutar el script (recomendado):
     Abre PowerShell, ve a la carpeta del proyecto "INFORMES SOLID"
     y ejecuta:
       .\Para_llevar\copiar_contenido.ps1

  2) Copiar manualmente desde la raíz del proyecto a "Para_llevar":
     - Carpeta "Reporte estado cuenta"
     - Carpeta "Reporte viaticos"
     - Carpeta ".vscode"

CONTENIDO QUE QUEDARÁ EN PARA_LLEVAR:
  • Reporte estado cuenta\   → Código Java y SQL del reporte de estado de cuenta
  • Reporte viaticos\        → Código Java del reporte de viáticos (informes, certificados, etc.)
  • .vscode\                 → Configuración de VS Code/Cursor (launch, settings)
  • .classpath, .project     → Proyecto Java/Eclipse

Para usar en otra ubicación: copia toda la carpeta "Para_llevar" donde quieras
y ábrela como proyecto en tu IDE. No olvides tener los JAR (itext, postgresql) en la misma raíz o en lib.
